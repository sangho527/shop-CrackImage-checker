쇼핑몰 이미지 검사기 사용 방법
==============================

카페24 쇼핑몰의 상품 이미지 중 깨진 것(엑박, 누락, 잘린 파일)을
자동으로 찾아서 엑셀로 정리해 주는 프로그램입니다.
설치 없이 ShopImageChecker.exe 파일 하나만 있으면 됩니다.


■ 사용 방법

1. ShopImageChecker.exe 를 더블클릭합니다.
   - 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면
     [추가 정보] → [실행] 을 누르세요. (회사 내부 프로그램이라 뜨는 안내입니다)
   - 프로그램이 뜨기까지 5~10초 걸릴 수 있습니다.

2. 쇼핑몰 주소를 입력합니다.
   - 쇼핑몰 전체 검사:  https://vivacious.kr/
   - 상품 1개만 검사:  상품 페이지 주소를 그대로 붙여넣기

3. [검사 시작] 을 누릅니다.
   - 전체 검사는 상품 수에 따라 5~20분 정도 걸립니다.
   - 처음 써 보신다면 [빠른 시험 검사] 를 체크하면 상품 30개만 1~2분 안에 검사합니다.
   - 검사 중에는 창을 닫지 마세요.

4. 끝나면 "결과 엑셀을 열까요?" 창이 뜹니다. [예] 를 누르면 바로 열립니다.
   결과 파일은 [문서 > 이미지검사 결과] 폴더에 날짜별로 저장됩니다.


■ 엑셀 결과 보는 법

[문제 이미지] 시트
  - 구분: 깨짐(빨강) = 고객 화면에서 이미지가 안 보임 / 주의(노랑) = 눈으로 확인 필요
  - 상품명, 상품 링크: 클릭하면 상품 페이지가 열립니다
  - 문제 유형: 왜 깨졌는지
  - 정상 파일 위치(교체용): 이 칸에 주소가 있으면 이미지를 다시 올릴 필요 없이
    상세설명의 이미지 주소만 이 주소로 바꾸면 해결됩니다

[상품별 요약] 시트
  - 전체 상품의 결과(정상/주의/깨짐)를 한눈에 볼 수 있습니다


■ 문제 유형별 해결 방법

- 이미지 서버 만료 (카페24 서비스 중지 페이지로 이동)
  → 예전 임시 주소(○○.openhost.cafe24.com)로 올린 이미지입니다.
    상세설명을 HTML 모드로 열어 그 주소를 쇼핑몰 주소로 바꾸면 해결됩니다.
- 이미지 누락 (404)
  → 파일이 삭제됐습니다. 이미지를 다시 올려야 합니다.
- 파일이 중간에 잘림 / 손상된 파일
  → 업로드 중 문제가 생긴 파일입니다. 원본으로 다시 올려 주세요.
- 하단 회색 띠 - 잘린 이미지 의심
  → 실제로 아래쪽이 잘렸는지 상품 페이지에서 눈으로 확인해 주세요.
- 상세 이미지 없음
  → 상세 이미지가 하나도 없는 상품입니다. 의도한 것인지 확인해 주세요.


■ 이럴 땐

- "상품을 찾지 못했습니다" → 주소에 오타가 없는지 확인하세요.
- 인터넷 오류가 난다 → 인터넷 연결을 확인하고 다시 시도하세요.
- 프로그램이 안 열린다 → 백신 프로그램이 막았을 수 있습니다. 담당자에게 문의하세요.
