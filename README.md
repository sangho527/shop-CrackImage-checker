# 쇼핑몰 이미지 검사기 (Shop Image Checker)

카페24 쇼핑몰의 **모든 상품 페이지를 자동으로 돌면서 깨진 상품 이미지를 찾아 엑셀로 정리**하는 도구입니다.
엑박, 누락, 업로드 중 잘린 파일처럼 눈으로 일일이 확인하기 어려운 문제를 한 번에 찾아냅니다.

## 무엇을 찾나요?

| 구분 | 문제 | 설명 |
|---|---|---|
| 깨짐 | 이미지 누락 (404) | 파일이 삭제되어 엑박으로 보임 |
| 깨짐 | 이미지 서버 만료 | 예전 임시 주소(`○○.openhost.cafe24.com`)로 올린 이미지 |
| 깨짐 | 파일이 중간에 잘림 | 업로드·전송 중 끊겨 일부만 표시되는 파일 |
| 깨짐 | 손상된 파일 / 0바이트 | 이미지로 열리지 않는 파일 |
| 깨짐 | 오류 페이지 응답 | 이미지 자리에 HTML 오류 페이지가 오는 경우 |
| 주의 | 하단 회색 띠 | 잘린 채로 다시 저장된 이미지 의심 (육안 확인) |
| 주의 | 상세 이미지 없음 | 상세 이미지가 하나도 없는 상품 |

서버가 만료된 이미지는 **쇼핑몰 주소에 같은 파일이 남아 있는지 자동으로 찾아**, 엑셀의 `정상 파일 위치(교체용)` 칸에 적어 줍니다. 이 경우 이미지를 다시 올리지 않고 주소만 바꾸면 해결됩니다.

## 결과 엑셀

- **문제 이미지**: 상품명, 상품번호, 상품 링크, 문제 유형, 이미지 위치(대표/상세), 이미지 URL, 교체용 주소
- **상품별 요약**: 전체 상품의 정상 / 주의 / 깨짐 결과
- **검사 정보**: 검사 시각, 검사한 상품·이미지 수, 문제 건수

## 사용 방법

### 1. 프로그램(.exe)으로 쓰기 — 개발자가 아닌 분께 권장

1. 이 저장소를 내려받습니다. (`Code` → `Download ZIP`)
2. 윈도우 PC에 [Python](https://www.python.org/downloads/)을 설치합니다. 설치할 때 **"Add python.exe to PATH"를 꼭 체크**하세요.
3. `build_exe.bat`을 더블클릭하면 1~3분 뒤 `ShopImageChecker.exe`가 생깁니다.
4. 팀원에게는 `ShopImageChecker.exe`와 [`docs/사용방법.txt`](docs/사용방법.txt)만 전달하면 됩니다. 받는 사람은 파이썬을 설치할 필요가 없습니다.

프로그램을 실행하면 쇼핑몰 주소를 입력하고 **[검사 시작]**만 누르면 됩니다. 결과는 `문서\이미지검사 결과` 폴더에 저장됩니다.

> 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**을 누르세요. 코드 서명이 없는 사내 프로그램이라 나오는 안내입니다.

### 2. 명령어로 쓰기

```bash
pip install -r requirements.txt

# 쇼핑몰 전체 검사
python shop_image_check.py https://vivacious.kr/

# 상품 1개만 검사
python shop_image_check.py "https://vivacious.kr/product/상품명/292/"

# 상품 30개만 시험 검사
python shop_image_check.py https://vivacious.kr/ --limit 30
```

윈도우에서는 `run_check.bat`을 더블클릭해도 됩니다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--limit` | 0 (전체) | 검사할 최대 상품 수 |
| `--workers` | 6 | 동시에 보내는 요청 수 (서버 부담이 걱정되면 낮추세요) |
| `--delay` | 0.2 | 목록 페이지 요청 간 대기 시간(초) |
| `--out` | 자동 | 결과 엑셀 파일 이름 |

## 파일 구성

| 파일 | 설명 |
|---|---|
| `shop_image_check.py` | 검사 엔진 (카페24 상품 수집 → 이미지 검사 → 엑셀 작성) |
| `image_checker_app.py` | 화면(GUI) 프로그램 |
| `build_exe.bat` | 윈도우 실행 파일(.exe) 만들기 |
| `run_check.bat` | 명령어 버전을 더블클릭으로 실행 |
| `docs/사용방법.txt` | 팀원 배포용 사용 설명서 |
| `generic_image_checker.py` | 카페24가 아닌 일반 사이트용 간단 검사기 (CSV·HTML 리포트) |

## 참고

- 카페24 쇼핑몰 구조에 맞춰져 있습니다. 다른 플랫폼에서는 `generic_image_checker.py`를 쓰세요.
- 자바스크립트로 이미지를 나중에 불러오는 페이지는 이미지가 수집되지 않을 수 있습니다.
- 모델 머리가 잘린 사진처럼 **파일은 정상인데 구도가 잘못된 사진**은 판단하지 못합니다.
